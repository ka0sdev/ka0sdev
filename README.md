### A little about me

I build software that solves problems I run into myself: developer tools, web apps, Windows utilities, and the infrastructure that keeps them running. My background spans software development and IT support, which has shaped how I think about usability, reliability, and the people on the other end of a support request.

I enjoy taking an idea from its first prototype through deployment, documentation, and the small details that make it pleasant to use. A lot of my work lives at the intersection of **developer experience**, **self-hosting**, and **practical automation**.
